# 🎮 HandVerseAI
### AI-Powered 3D Adventure Game Controlled by Hand Gestures

**Play with your hands. Explore a virtual world. Experience the future of gaming.**

HandVerseAI is an AI-powered interactive 3D adventure game that uses real-time hand gesture recognition to control gameplay. Instead of relying entirely on a keyboard or mouse, players can interact with the virtual environment through natural hand movements captured by a camera.

The project combines Artificial Intelligence, Computer Vision, and 3D Game Development to create a more immersive, intuitive, and engaging gaming experience.
